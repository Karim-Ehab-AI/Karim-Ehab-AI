## Featured Projects

### AI-Powered Applicant Tracking System

An AI-powered recruitment system combining hybrid retrieval with explainable candidate ranking.

- Hybrid semantic and lexical search.
- Modular architecture with interchangeable AI providers.
- Explainable scoring based on relevance, skills, experience, and education.
- Architecture focused on inference efficiency and workload isolation.

**Results:** 95.56% Precision@5 | 91.10% NDCG@10

### AI First-Aid Assistant

A bilingual first-aid assistant powered by RAG and hybrid retrieval.

- Dense and sparse retrieval with Reciprocal Rank Fusion (RRF).
- Voice queries using speech-to-text.
- Independent services for document parsing and embedding generation.
- Evaluation using Ragas for answer relevance and faithfulness.

**Results:** 98% Answer Relevancy | 0.96 Faithfulness across 25 evaluation queries.
