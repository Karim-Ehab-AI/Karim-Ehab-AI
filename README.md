# Karim Ehab | AI Engineer

AI Engineer focused on building production-grade AI systems, with hands-on experience in NLP, LLMs, RAG, and AI-powered applications.

I approach AI engineering beyond model integration. I focus on system architecture, retrieval quality, inference efficiency, and designing maintainable systems that adapt to changing requirements.

My work on an AI-powered Applicant Tracking System (ATS) involved hybrid retrieval, explainable candidate ranking, and architectural decisions focused on workload isolation and flexibility across AI providers. The system achieved **95.56% Precision@5** and **91.10% NDCG@10** across an evaluation set of 150 CVs and 30 job descriptions.

Beyond engineering, I have experience mentoring learners through Google Developer Groups and creating technical content on YouTube about LLMs, RAG, and AI engineering.

My goal is to build reliable, efficient, and scalable AI systems that solve real-world problems.

## Featured Projects

### AI-Powered Applicant Tracking System

An AI-powered candidate search and ranking system designed to improve recruitment workflows through hybrid retrieval and explainable ranking.

- Implemented hybrid retrieval using semantic and lexical search.
- Designed a modular architecture with interchangeable AI providers.
- Built an explainable scoring system combining relevance, skills, experience, and education.
- Focused on inference efficiency, workload isolation, and reducing repeated computation.
- Evaluated retrieval quality across 150 CVs and 30 job descriptions.

**Evaluation:** 95.56% Precision@5 | 91.10% NDCG@10

### AI First-Aid Assistant

A bilingual first-aid assistant built using Retrieval-Augmented Generation, hybrid search, and evaluation-driven quality checks.

- Implemented dense and sparse retrieval with Reciprocal Rank Fusion (RRF).
- Integrated voice queries through speech-to-text.
- Deployed document parsing and embedding generation as independent services.
- Evaluated answer relevance, faithfulness, and citation grounding using Ragas.

**Evaluation:** 98% Answer Relevancy | 1.0 Faithfulness across 25 evaluation queries.
